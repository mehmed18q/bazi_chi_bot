## دربارهٔ پروژه

بازی‌چی با **Python 3.14** و **aiogram 3** ساخته شده و از طریق Telegram Bot API با
**long polling** کار می‌کند. بازی، نوبت، امتیاز، دعوت، پرداخت و زمان‌بندی‌ها در
**SQLite** ذخیره می‌شوند؛ بنابراین بازیکن می‌تواند بعد از راه‌اندازی دوبارهٔ ربات،
بازی ناتمامش را ادامه دهد.

شش بازی، رابط فارسی با دکمه‌های خود تلگرام، مسابقهٔ خصوصی و گروهی، حریف رباتی،
تورنومنت و چالش روزانه در یک ربات جمع شده‌اند. ساختار کد، مرز تراکنش‌ها و شیوهٔ
توسعه در [راهنمای معماری](ARCHITECTURE.md) توضیح داده شده است.

## امکانات اصلی

- **بازی ماندگار:** ادامهٔ بازی ناتمام، نمایش آخرین نتیجه و حفظ تاریخچهٔ امتیازها پس از restart.
- **چند شیوهٔ بازی:** دونفره، تک‌نفره با ربات، تورنومنت، مسابقهٔ گروهی و چالش روزانه.
- **رقابت و امتیاز:** جدول ماهانه و همهٔ دوره‌ها، جایگاه بازیکن، پاداش ورود ماهانهٔ مشترکان ویژه و جایزهٔ نفر اول ماه.
- **دعوت دوستان:** لینک اختصاصی و اعتباردهی دعوت از لینک بازی یا گروه؛ فعال‌سازی خودکار اشتراک پس از رسیدن به حد نصاب.
- **پرداخت و مدیریت:** دریافت رسید متنی یا تصویری، پرداخت native کیف‌پولی بله، بررسی ادمین، تنظیم مبلغ و کارت، فعال‌سازی مستقیم کاربر و مدیریت اسپانسرها.
- **پایداری اجرا:** مهاجرت خودکار دیتابیس، تراکنش‌های SQLite و کنترل نسخهٔ بازی برای جلوگیری از ثبت دوبارهٔ callback.
- **اتصال دو پیام‌رسان:** تلگرام و بله با یک منطق و دیتابیس مشترک؛ پیام‌های خصوصی بازی از بازوی درست ارسال می‌شوند.

## بازی‌ها و حالت‌های اجرا

| بازی | خلاصهٔ قانون |
|---|---|
| 🌸 **گل یا پوچ** | یک نفر گل را در مشت پنهان می‌کند؛ نفر مقابل یک بار حدس می‌زند. نقش‌ها در دست بعد عوض می‌شوند. |
| ❌⭕ **دوز سه‌تایی** | بازیکن‌ها به نوبت خانه‌ها را پر می‌کنند؛ سه علامت پشت سر هم، یک برد است. |
| ✊✋✌️ **سنگ، کاغذ، قیچی** | حرکت هر نفر تا انتخاب هر دو مخفی می‌ماند؛ دست مساوی هم از تعداد دست‌ها حساب می‌شود. |
| 🔤 **حدس کلمه** | سازنده کلمه‌ای ۲ تا ۲۰ حرفی می‌دهد؛ حدس‌زننده به تعداد حروف فرصت دارد. 🟩 جای درست، 🟨 حرف در جای دیگر و ⬛ حرف ناموجود را نشان می‌دهد. |
| 🎨 **فکر بکر** | کد چهاررنگ از شش رنگ ساخته می‌شود؛ تکرار رنگ مجاز است و هر دور ۸ تلاش دارد. مهرهٔ سیاه جای درست و مهرهٔ سفید رنگ درست در جای دیگر را نشان می‌دهد. |
| 🎭 **جرئت یا حقیقت** | سؤال یا چالش از بانک انتخاب می‌شود؛ پاسخ با داوری نفر مقابل یا رأی گروه امتیاز می‌گیرد. |

| حالت | دسترسی و شیوهٔ اجرا |
|---|---|
| **تک‌نفره با ربات** | پنج بازی نخست، رایگان؛ تعداد دست/دور انتخابی: ۳، ۵، ۷ یا ۹. |
| **چالش روزانه** | رایگان؛ هر روز به وقت تهران از **۱۲:۰۰ تا ۱۳:۰۰**، یک تلاش برای هر کاربر. یادآور اختیاری در ۱۱:۵۵ ارسال می‌شود. |
| **دونفره** | با اشتراک ویژه؛ ساخت بازی و فرستادن لینک دعوت برای دوست. |
| **تورنومنت** | با اشتراک ویژه؛ ۲ تا ۶ بازی متفاوت در حالت دونفره یا ۲ تا ۵ بازی در حالت تک‌نفره، به ترتیب انتخاب بازیکن. تعداد دست/دور هر بازی جدا انتخاب می‌شود. |
| **گروهی** | با اشتراک ویژه؛ یک نفر بازی را می‌سازد، اعضا «حاضرم!» می‌زنند و سازنده مسابقه را شروع می‌کند. هر شش بازی حالت گروهی دارند. |

در پنج بازی غیر از «جرئت یا حقیقت»، سازندهٔ بازی دونفره یا گروهی می‌تواند
**چالش پایانی** را فعال کند. بازندهٔ بازی دونفره یا آخرین نفر جدول گروه،
«حقیقت» یا «جرئت» را انتخاب می‌کند؛ تأیید پاسخ یک امتیاز اضافه می‌دهد.
بازی تک‌نفره، چالش روزانه و تورنومنت چالش پایانی ندارند.

ربات در گل یا پوچ و سنگ، کاغذ، قیچی از انتخاب‌های پیشین ثبت‌شده برای تصمیم‌گیری
کمک می‌گیرد. بانک حدس کلمه بیش از ۵۰۰ واژهٔ فارسی دارد و از واژه‌های ساخته‌شدهٔ
بازیکن‌های دیگر هم استفاده می‌کند؛ کلمهٔ ربات برای همان بازیکن در بازی تک‌نفره
و چالش روزانه تکرار نمی‌شود.

## راه‌اندازی سریع

### پیش‌نیازها

- Python **3.14 یا جدیدتر**
- توکن ربات از BotFather تلگرام و در صورت نیاز توکن بازوی بله از botfather بله
- دسترسی سرور به API پیام‌رسان‌ها، مستقیم یا از طریق proxy

از ریشهٔ پروژه:

```bash
python3.14 -m venv .venv
.venv/bin/python -m pip install -e .
cp -n .env.example .env
```

در `.env` مقدار `TELEGRAM_BOT_TOKEN` را با توکن واقعی جایگزین کنید. برای فعال‌کردن بله،
`BALE_BOT_TOKEN` را هم قرار دهید؛ هر دو بازو با همان `DATABASE_PATH` اجرا می‌شوند
و در منوی اصلی دکمهٔ ورود/اتصال به بازوی بله نمایش داده می‌شود. نمونهٔ فایل، proxy محلی تلگرام دارد؛ اگر اتصال مستقیم می‌خواهید، مقدار `TELEGRAM_PROXY_URLS` را به
`'[]'` تغییر دهید. بله بدون proxy مستقیم به `https://tapi.bale.ai` وصل می‌شود. برای فعال‌کردن پرداخت کیف‌پولی بله،
`BALE_PAYMENT_PROVIDER_TOKEN` را در `.env` قرار دهید؛ مدیر می‌تواند آن را روشن یا خاموش کند. سپس ربات را اجرا کنید:

```bash
.venv/bin/bazi_chi_bot
```

اجرای مستقیم فایل ورودی هم ممکن است:

```bash
PYTHONPATH=src .venv/bin/python main.py
```

با `/start` در گفت‌وگوی خصوصی ربات، منوی اصلی باز می‌شود. از «شروع بازی»
می‌توان بازی تک‌نفره را آغاز کرد؛ برای بازی دونفره، پس از داشتن اشتراک ویژه،
لینک دعوت ساخته می‌شود. فرمان‌های عمومی دیگر: `/games`، `/lastgame`،
`/stats`، `/leaderboard` و `/help`.

### اتصال حساب تلگرام و بله

هر کاربر در دیتابیس یک حساب canonical دارد. از منوی اصلی روی «ورود/اتصال»
بزنید و لینک پیام‌رسان دیگر را فقط خودتان باز کنید؛ لینک یک‌بارمصرف و ۱۵ دقیقه
معتبر است. پس از اتصال، بازی‌های ناتمام، امتیاز، آمار و اشتراک در هر دو بازو
با همان حساب ادامه پیدا می‌کند. مدیر می‌تواند پیام‌رسان‌های متصل و شناسهٔ هرکدام
را در پروندهٔ کاربر ببیند.

### استفاده در گروه

در BotFather گزینهٔ `/setjoingroups` را فعال کنید. فرمان `/play` در گروه
مسابقهٔ چندنفره می‌سازد. اگر می‌خواهید ربات به نام «بازی چی» در پیام‌های عادی
گروه هم پاسخ دهد، `Privacy Mode` را با `/setprivacy` غیرفعال کنید و ربات را
دوباره به گروه اضافه کنید. فعال‌کردن حالت inline لازم نیست.

بازیکن‌ها پیش از شروع باید در خصوصی ربات `/start` زده و اشتراک ویژه داشته
باشند. کلمه، کد و حدس‌های محرمانه در خصوصی با دستورهای نشان‌داده‌شده روی
کارت گروه، از جمله `/gword` و `/gcode`، فرستاده می‌شوند؛ گروه فقط پیشرفت
و امتیاز را می‌بیند. امتیاز مسابقهٔ گروهی در همان مسابقه نگهداری می‌شود.

## تنظیمات

تنظیمات از فایل `.env` در پوشهٔ اجرا خوانده می‌شوند. [`.env.example`](.env.example)
الگوی اولیه است و `.env` در Git ثبت نمی‌شود.

| متغیر | کاربرد | پیش‌فرض |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن BotFather تلگرام؛ الزامی | — |
| `BALE_BOT_TOKEN` | توکن اختیاری بازوی بله | خالی؛ بله غیرفعال |
| `BALE_API_BASE_URL` | نشانی API بله | `https://tapi.bale.ai` |
| `BALE_PAYMENT_PROVIDER_TOKEN` | توکن پرداخت کیف‌پولی بله؛ فقط در محیط اجرا | خالی؛ پرداخت بله بدون توکن غیرفعال |
| `DATABASE_PATH` | مسیر دیتابیس SQLite | `data/bazi_chi_bot.sqlite3` |
| `LOG_LEVEL` | سطح لاگ | `INFO` |
| `TELEGRAM_PROXY_URLS` | آرایهٔ JSON از proxyها به ترتیب اولویت | `[]`؛ اتصال مستقیم |
| `TELEGRAM_ADMIN_IDS` | شناسه‌های عددی مدیران ربات، جداشده با ویرگول | خالی |
| `TELEGRAM_PAYMENT_REVIEWER_IDS` | شناسه‌های بررسی‌کنندگان رسید، جداشده با ویرگول | `1767552952` |
| `BALE_ADMIN_IDS` | شناسه‌های مدیران در بله | خالی |
| `BALE_PAYMENT_REVIEWER_IDS` | شناسه‌های بررسی رسید در بله | خالی |
| `COUNTDOWN_TIMEZONE` | منطقهٔ زمانی تاریخ شمارش‌معکوس | `Asia/Tehran` |

برای اتصال از طریق proxy:

```dotenv
TELEGRAM_PROXY_URLS='["socks5://127.0.0.1:1080", "http://127.0.0.1:7890"]'
```

ربات آدرس‌ها را به‌ترتیب آزمایش می‌کند و اولین اتصال سالم را به کار می‌گیرد.
اتصال فعال و proxyهای ناموفق هر **۱۰ دقیقه** دوباره بررسی می‌شوند. آدرس‌های
`socks5://` و `http://` پشتیبانی می‌شوند. لینک اشتراک V2Ray/Clash/sing-box
را ابتدا در یک کلاینت proxy به خروجی محلی تبدیل کنید و آدرس آن خروجی را
در آرایه بگذارید.

> [!IMPORTANT]
> برای سرور، `DATABASE_PATH` را بیرون از پوشهٔ Git، مثلاً
> `/var/lib/bazi_chi_bot/bazi_chi_bot.sqlite3`، تنظیم کنید و از `.env` و
> دیتابیس پشتیبان بگیرید. اگر دیتابیس زنده هنوز داخل checkout است،
> [مراحل جابه‌جایی اولیه](DEPLOYMENT.md) را پیش از به‌روزرسانی انجام دهید.

## دسترسی ویژه، پرداخت و دعوت

`/start`، پنج بازی تک‌نفره، چالش روزانه و یادآور آن رایگان‌اند. بازی دونفره،
تورنومنت و مسابقهٔ گروهی به **اشتراک ویژهٔ بدون انقضا** نیاز دارند.
فعال‌سازی می‌تواند از راه تأیید رسید، تصمیم مستقیم مدیر یا رسیدن دعوت‌ها
به حد نصاب انجام شود. حساب بازی مشترک است، اما فعال‌سازی برای هر پیام‌رسان
جدا ثبت می‌شود. فعال‌سازی هم‌زمان تلگرام و بله یک‌ونیم برابر هزینهٔ یک پلتفرم
است؛ اگر پلتفرم دوم را بعداً فعال کنید، فقط مبلغ پایهٔ همان پلتفرم را می‌پردازید.

در «اشتراک ویژه»، مبلغ یک پلتفرم از **مبلغ پایه + شناسهٔ داخلی کاربر** ساخته
می‌شود و قبل از پرداخت، دامنهٔ فعال‌سازی (همین پلتفرم یا هر دو) انتخاب می‌شود.
کاربر رسید متنی یا تصویری می‌فرستد؛ بررسی‌کنندگان رسید آن را تأیید
یا رد می‌کنند. اعتبار رسید باید توسط مدیر بررسی شود. در بله، دکمهٔ پرداخت
کیف‌پولی با `sendInvoice` مبلغ را به ریال می‌فرستد و اشتراک فقط بعد از
`successful_payment` فعال می‌شود. مدیر از «مدیریت ربات ← تنظیمات پرداخت» مبلغ
پایه، شمارهٔ کارت و نام صاحب کارت را تغییر می‌دهد و پرداخت بله را روشن یا خاموش می‌کند؛
برای روشن‌کردن آن باید `BALE_PAYMENT_PROVIDER_TOKEN` تنظیم شده باشد.
از «کاربران ربات» هم می‌تواند دسترسی هر کاربر را مستقیم فعال یا غیرفعال کند.

هر کاربر در «دعوت دوستان» لینک اختصاصی می‌گیرد. ورود دوست از آن لینک،
لینک بازی دونفره یا لینک گروه **۱ امتیاز** دارد و فعال‌شدن اشتراک همان دوست
**۱ امتیاز دیگر** می‌دهد. هر دعوت‌شونده فقط به یک دعوت‌کننده نسبت داده
می‌شود؛ دعوت خود، تکراری یا حساب ازپیش‌فعال شمرده نمی‌شود. حد نصاب
پیش‌فرض **۱۰ دعوت فعال‌شده** است و مدیر آن را از «تنظیمات دعوت» تغییر
می‌دهد؛ هدف دوم برای فعال‌سازی پلتفرم دوم، یک‌ونیم برابر حد نصاب اول است
(پیش‌فرض ۱۵ دعوت فعال). دعوت ثبت‌شده تا پایان فرایند پرداخت کاربر باقی می‌ماند.

کاربر می‌تواند از «نام نمایشی» نامی بین ۱ تا ۴۰ کاراکتر انتخاب کند یا دوباره
از نام تلگرامش استفاده کند. نام شخصی‌سازی‌شده با `/start` بازنویسی نمی‌شود.

## امکانات مدیر

شناسهٔ مدیران را در `TELEGRAM_ADMIN_IDS` بگذارید و ربات را دوباره اجرا کنید.
شناسه‌های `TELEGRAM_PAYMENT_REVIEWER_IDS` هم در نسخهٔ فعلی به فهرست مدیران
افزوده می‌شوند؛ این دو مقدار را با توجه به دسترسی مدیریتی تنظیم کنید.
گزینهٔ «مدیریت ربات» به این افراد نمایش داده می‌شود و امکانات زیر را دارد:

| بخش | کار |
|---|---|
| **کاربران ربات** | مشاهدهٔ پرونده و فعال/غیرفعال‌کردن اشتراک |
| **تنظیمات پرداخت و دعوت** | تغییر مشخصات پرداخت و حد نصاب دعوت |
| **افزودن سؤال** | افزودن حقیقت یا جرئت به بانک عمومی |
| **مدیریت اسپانسرها** | افزودن، فعال/غیرفعال‌کردن و حذف اسپانسر کانالی یا رباتی؛ بررسی عضویت برای کانال‌های فعال |
| **شمارش‌معکوس** | ساخت و لغو پیام‌های زمان‌بندی‌شده برای کاربران ثبت‌شده |

برای شمارش‌معکوس، مخاطب باید قبلاً ربات را آغاز کرده باشد. تاریخ ورودی میلادی
و در منطقهٔ زمانی `COUNTDOWN_TIMEZONE` است:

```text
/countdown @username 2027-01-01 21:30
/countdowns
/cancelcountdown @username
```

مدیر می‌تواند همین کار را از دکمهٔ «شمارش‌معکوس» انجام دهد. پیام نخست
بلافاصله ارسال می‌شود؛ سپس فاصلهٔ ارسال با نزدیک‌شدن به زمان هدف از
یک ساعت به ده دقیقه، پنج دقیقه و در دقیقهٔ آخر به ده ثانیه کاهش می‌یابد.
وضعیت در SQLite می‌ماند و پس از راه‌اندازی مجدد ادامه پیدا می‌کند.

## بانک حقیقت و جرئت

بانک سؤال در دیتابیس نگهداری می‌شود و **دیتابیس تازه، بانک اولیهٔ پرشده
ندارد**. مدیر می‌تواند از منوی ربات سؤال اضافه کند یا یک کاتالوگ JSON
بازبینی‌شده را وارد کند:

```json
{
  "questions": [
    {"kind": "truth", "text": "متن یک سؤال حقیقت"},
    {"kind": "dare", "text": "متن یک چالش جرئت"}
  ]
}
```

```bash
.venv/bin/python -m bazi_chi_bot.import_questions /path/to/questions.fa.json
```

فایل نمونهٔ سؤال در این مخزن وجود ندارد؛ مسیر بالا باید به فایل خودتان اشاره
کند. فرمان import پیش از تغییر از دیتابیس موجود پشتیبان می‌گیرد، سؤال تکراری
را دوباره نمی‌سازد و سؤال موجود را برای انتخاب عمومی فعال می‌کند. در
پایان هر سؤال، پاسخ بازیکن و داوری ذخیره می‌شود. سؤال برای همان ترتیب
پاسخ‌دهنده و هم‌بازی تکرار نمی‌شود؛ اگر مورد تازه‌ای نمانده باشد، بازیکن
مجاز متن تازه می‌نویسد.

## داده، استقرار و نگهداری

### اجرای دائمی با systemd

نمونهٔ [`bazi_chi_bot.service`](bazi_chi_bot.service) پروژه را از
`/opt/bazi_chi_bot` اجرا می‌کند. مسیر پروژه، کاربر سرویس و فایل `.env`
را با محیط خودتان تطبیق دهید؛ نمونه با کاربر `root` تعریف شده است.
برای نصب نمونه:

```bash
sudo install -m 0644 bazi_chi_bot.service /etc/systemd/system/bazi_chi_bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now bazi_chi_bot.service
sudo systemctl status bazi_chi_bot.service
```

برای دیدن لاگ زنده:

```bash
sudo journalctl -u bazi_chi_bot.service -f
```

فرمان‌های پشتیبان‌گیری، به‌روزرسانی تکرارپذیر و بازگشت در
[راهنمای استقرار](DEPLOYMENT.md) آمده‌اند. اسکریپت
[`scripts/deploy.sh`](scripts/deploy.sh) از شاخهٔ تمیز `master`،
پس از گرفتن پشتیبان و اجرای تست‌ها، سرویس را به‌روز می‌کند.

### انتقال یک‌طرفهٔ snapshot سرور

پس از استقرار موفق، snapshot دیتابیس سرور در شاخهٔ جداگانهٔ
`server-data` منتشر می‌شود. برای انتشار دستی یا تلاش دوباره پس از خطای
Git، روی سرور اجرا کنید:

```bash
bash scripts/publish_server_data.sh
```

برای دریافت فقط یک کپی روی سیستم محلی:

```bash
.venv/bin/python scripts/server_data.py fetch
```

فایل دریافتی در `data/server_snapshot.sqlite3` ذخیره می‌شود و دیتابیس
فعال محلی را جایگزین نمی‌کند. این مسیر فقط برای **سرور ← لوکال** است؛
شاخهٔ `server-data` را با `master` ادغام نکنید. snapshot شامل اطلاعات
کاربران است؛ مخزن راه‌دور باید خصوصی باشد و مجوز نوشتن شاخهٔ داده روی
Git server فقط به حساب سرور داده شود. دیتابیس مستقل ابزار دعوت
`invitation/phones.sqlite3` در این انتقال نیست.

### بازنشانی سابقهٔ بازی

این فرمان برای عملیات مدیریتی عمدی است:

```bash
.venv/bin/python -m bazi_chi_bot.reset_database
```

پیش از تغییر، پشتیبان SQLite می‌سازد؛ سپس سابقهٔ بازی‌ها، امتیازها،
تورنومنت‌ها، چالش‌های روزانه و شمارش‌معکوس‌ها را پاک می‌کند و آمار را
صفر می‌کند. کاربران، وضعیت اشتراک، تنظیمات پرداخت، رسیدها و بانک سؤال
حفظ می‌شوند. آن را در فرایند عادی استقرار اجرا نکنید.

## ابزار مستقل دعوت کاربران رضایت‌داده

[`invitation/send_opt_in_invitations.py`](invitation/send_opt_in_invitations.py)
ابزاری جدا از ربات است. فهرست تماسِ دارای رضایت را از
`phones/all_phones.xlsx` به `invitation/phones.sqlite3` وارد می‌کند؛
فایل اکسل و دیتابیس تماس‌ها در Git ثبت نمی‌شوند. این ابزار برای ارسال
از **اکانت تلگرام** با Telethon به `TELEGRAM_API_ID` و
`TELEGRAM_API_HASH` نیاز دارد.

```bash
.venv/bin/python -m pip install -e '.[outreach]'
.venv/bin/python invitation/send_opt_in_invitations.py --import-excel
.venv/bin/python invitation/send_opt_in_invitations.py --source test --count 1 --dry-run --bot-link https://t.me/YourBot
.venv/bin/python invitation/send_opt_in_invitations.py --source test --count 1 --bot-link https://t.me/YourBot
```

پیش‌نمایش بدون اتصال به تلگرام انجام می‌شود. `--count` تعداد ردیف‌های
بررسی‌شده در همان اجراست؛ موفقیت و خطا در دیتابیس مستقل ثبت می‌شوند.
سقف پیش‌فرض **۲۰ ارسال موفق در روز** و فاصلهٔ پیش‌فرض **۱۲۰ ثانیه**
است. اجرای دوباره وضعیت‌های نهایی را تکرار نمی‌کند؛ وضعیت `SENDING`
پس از وقفهٔ ناگهانی نیاز به بررسی دستی دارد. برای پاک‌سازی شماره‌های
دیتابیس موجود، `--normalize-phones` را اجرا کنید.

## توسعه و آزمون

وابستگی‌های توسعه و ابزار دعوت را نصب کنید:

```bash
.venv/bin/python -m pip install -e '.[test,outreach]'
```

سپس:

```bash
.venv/bin/ruff check src tests
.venv/bin/ruff format --check src tests
.venv/bin/pytest -q
```

تست‌ها قوانین بازی، مهاجرت SQLite، بازیابی پس از restart، پرداخت و
دعوت، گروه، تورنومنت و callbackهای تکراری یا هم‌زمان را پوشش می‌دهند.
آزمون فقط‌خواندنی بانک سؤال، اگر دیتابیس محلی موجود نباشد، skip می‌شود؛
راهنمای استقرار بررسی بانک واقعی سرور را جداگانه انجام می‌دهد.

| جزء | فناوری |
|---|---|
| زبان و اجرا | Python 3.14+، long polling |
| رابط تلگرام | aiogram 3 |
| ذخیره‌سازی | SQLite، aiosqlite |
| تنظیمات | pydantic-settings و `.env` |
| ابزار دعوت | Telethon و openpyxl، به‌صورت وابستگی اختیاری |
| آزمون و کیفیت کد | pytest و Ruff |

نسخهٔ برنامه در [`pyproject.toml`](pyproject.toml) و
[`src/bazi_chi_bot/__init__.py`](src/bazi_chi_bot/__init__.py)
برابر `0.1.0` است.
